1. Executive Summary

1.1 Product Overview

It combines hotel operations, guest experience, employee management, financial controls, and AI-powered intelligence into a single unified platform.

To be the leading hotel operating system for luxury hospitality in Africa and beyond, combining enterprise control, modern cloud automation, and exceptional guest personalization.

4. Module Guide

4.1 Authentication & Access Control

Login

Users authenticate via email and password. JWT tokens are issued with 12-hour expiry and stored in localStorage. Token rotation occurs on each API call.

Role-Based Access Control (RBAC)

RoleAccess
ADMINFull system access, settings, user management, payroll
MANAGERAll operational modules, reports, approvals, scheduling
FRONT_DESKReservations, check-in/out, guest CRM, front desk
HOUSEKEEPINGHousekeeping tasks, room status updates
RESTAURANTF&B orders, menu management, room service
MAINTENANCEMaintenance requests, work orders
STAFFBasic access, shifts, profile, swaps

Guest Authentication

Guests authenticate via confirmation number + last name (no account required). Separate JWT with 24-hour expiry and /api/guest/* namespace.

4.2 Executive Dashboard

The dashboard provides real-time operational visibility:

  • Occupancy Rate — Live room occupancy percentage with trend
  • Revenue Today — Today's revenue in selected currency
  • Arrivals/Departures — Expected check-ins and check-outs
  • Guest Satisfaction — Average rating from feedback
  • Revenue Chart — 7-day/30-day/1-year revenue trend
  • VIP Arrival — Next VIP guest with preferences
  • Room Operations — Live room status table
  • Housekeeping/Maintenance SLA — Task completion rates
  • Service Activity Feed — Real-time operational events

4.3 Reservations & Booking

Features

  • Full CRUD for reservations with inline guest creation
  • Room availability calendar with real-time updates
  • Booking sources: Direct, OTA, Corporate, Travel Agent
  • VIP flagging and priority handling
  • Confirmation number generation (RH-XXXXXXXX format)
  • Folio creation on booking
  • Status workflow: PENDING → CONFIRMED → CHECKED_IN → CHECKED_OUT

4.4 Front Desk Operations

Daily Operations

  • Today's Arrivals — Guests expected to check in
  • Today's Departures — Guests expected to check out
  • One-Click Check-In — Updates reservation status, room status, creates folio
  • One-Click Check-Out — Settlement, room release, status update
  • Special Requests — Displayed on arrival cards

8. Security & Compliance

8.1 Authentication

  • JWT tokens with 12-hour expiry (staff) / 24-hour (guest)
  • bcrypt password hashing (12 rounds)
  • Separate guest authentication namespace
  • Token stored in localStorage with auto-logout on 401

8.2 Authorization

  • Role-based access control (RBAC) enforced on all endpoints
  • Property-scoped access for multi-property support
  • Guest access limited to own reservation data

8.3 Audit Trail

  • Every API action logged with user, action, entity, details, IP, timestamp
  • Immutable audit logs (append-only)
  • Viewable in Settings → Audit Trail

8.4 Data Protection

  • Passwords never stored in plaintext
  • Guest PII protected by role-based access
  • Database connection pooling with idle timeout
  • Input validation on all endpoints
  • SQL injection prevention via parameterized queries
