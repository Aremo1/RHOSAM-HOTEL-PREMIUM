1. Document Overview

1.1 Purpose

This document defines the User Acceptance Testing (UAT) plan for the RHoSAM Hotel & Suites Premium Management Platform. UAT validates that the system meets real-world business requirements from the perspective of actual hotel staff and guests. The business stakeholders (hotel management, department heads, and guest representatives) will execute these scenarios to formally accept the system for production deployment.

1.2 Scope

All user-facing functionality across admin portal, employee workflows, and guest mobile app. Focus areas:

  • Business workflow validation (booking → check-in → stay → check-out)
  • Guest experience validation (mobile app, digital key, room controls)
  • Operational efficiency (scheduling, housekeeping, maintenance)
  • Financial accuracy (payments, multi-currency, folio management)
  • Real-time functionality (notifications, room controls, WebSocket)
  • Usability and user experience

2. UAT Strategy & Approach

2.1 Test Approach

UAT uses realistic business scenarios executed by actual end users in a test environment seeded with representative data. Each scenario follows a complete business workflow from the user's perspective — no API-level or technical testing.

2.2 Pass/Fail Criteria

ResultDefinition
PASSAll expected outcomes met, user can complete workflow without assistance
FAIL — BlockerUser cannot complete critical business workflow
FAIL — MajorWorkflow completable but with significant workaround or data error
FAIL — MinorCosmetic issue, non-critical, doesn't impede workflow

8. User Acceptance Scenarios — Manager

UAT-MGR-001: AI Auto-Schedule with Preferences
CRITICAL

Goal: Manager uses AI to generate an optimal shift schedule and reviews suggestions.

1. Login as Manager
2. Navigate to Scheduling
3. Click "AI Auto-Schedule"
4. Review Demand Forecast tab (occupancy, staffing needs)
5. Review Preferences tab (employee preferences)
6. Go to Generate tab → Click "Generate Optimal Schedule"
7. Review results: shifts created, warnings, summary
8. Verify calendar populated with color-coded shift cards
Expected: AI generates shifts respecting employee preferences, no overlaps, departments adequately staffed. Warnings shown for any gaps. Calendar visually populated.
UAT-MGR-002: Approve Shift Swap Request
HIGH

Goal: Manager reviews and approves an employee's shift swap request.

1. (Employee submits swap request via scheduling calendar)
2. Login as Manager
3. Navigate to Swaps
4. Find pending swap request
5. Click to view details (both shifts side-by-side)
6. Add reviewer notes: "Approved — coverage adequate"
7. Click "Approve"
8. Navigate to Scheduling → Verify shifts swapped on calendar
Expected: Swap details clearly displayed. Approval executes the trade. Both employees' shifts updated on calendar. Status changes to APPROVED.
UAT-MGR-003: View Conflict Alerts and Labor Costs
HIGH

Goal: Manager reviews schedule health and labor cost analysis.

1. Login as Manager
2. Navigate to Scheduling
3. Click "Conflicts" button → Review conflict panel
4. Note any critical/warning issues
5. Close conflict panel
6. Click "Costs" button → Review labor cost analysis
7. Review total cost, department breakdown, optimization suggestions
Expected: Conflict panel shows clear categorized issues with severity. Cost panel shows total cost, regular/overtime/premium breakdown. Optimization suggestions with potential savings displayed.

CRITICAL

Expected: Guest receives push notification within 2 seconds of status change. Toast shows with correct order details. Notification bell shows unread count.
UAT-GUEST-003: Digital Room Key Unlock
HIGH

Goal: Guest can unlock room using digital key (NFC simulation and QR code).

1. Login as guest → Navigate to Key tab
2. Click "Tap to Unlock" (NFC simulation)
3. Verify green pulsing animation → "Room unlocked!" message
4. Click "QR Code" → Verify QR pattern displayed with key code
5. Check Access History → Verify unlock logged
Expected: NFC unlock works with animation feedback. QR code generates correctly. Access log records both unlock methods with timestamps.
UAT-GUEST-004: Room Controls (Lights, AC, TV)
HIGH

Goal: Guest controls room environment via mobile app.

1. Login as guest → Navigate to Room tab
2. Toggle "Main Lights" on/off
3. Toggle "Bedroom" lights on
4. Adjust AC temperature to 20°C using +/- buttons
5. Change AC mode to "COOL"
6. Turn TV on → Adjust channel → Adjust volume
7. Toggle "Do Not Disturb" on
8. Close and reopen Room tab → Verify all settings persisted
Expected: All toggles respond immediately. Temperature display updates. TV controls work. DND state persists. "Saving..." indicator shown during updates. State maintained across tab switches.
